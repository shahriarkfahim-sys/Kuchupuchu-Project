# ECD source documents

`ECD_App_Coder_Technical_Documentation.txt` and `ECD_Complete_Pregnancy_and_Child_Database.xlsx` are the supplied source documents for pregnancy and child-assessment questions, answer options, and scoring thresholds.

`src/data/ecdQuestionBank.json` is the app-ready question bank transcribed from the workbook. The three source options retain their workbook order and use the documentation's 2, 1, 0 point weights. The assessment summarizes the selected timeline group using the documented 80/50 percent thresholds.
