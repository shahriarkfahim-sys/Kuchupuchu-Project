# Software Requirement Specification (SRS) & System Architecture
## Project: Early Childhood Development (ECD) & Pregnancy Tracking Web Application (Bangladesh)
## Feature: Data Analytics, Scoring Engine, Vaccine Alert & Interactive Spider Chart Logic

---

## 1. System Overview & Objective
This document outlines the technical specification for the backend scoring engine, database mapping, and frontend report visualization logic for the ECD tracking web app. The platform evaluates pregnancy progress and child milestone development across five global domains plus a local vaccine adherence tracker.

The core objective is to ingest user inputs from a multi-choice radio-button form, apply mathematical weights, calculate domain-specific percentiles, trigger localized validation alerts (e.g., Bangladesh EPI Vaccination Schedule), and render an interactive multi-axis Spider Chart with localized action items.

---

## 2. Database Schema & Data Models

## 3. Mathematical Scoring Engine & Algorithmic Logic
For any given submission, the backend must group the answers array by the `domain` column. For each isolated domain, compute the percentage using the following mathematical formula:

$$\text{Domain Score (\%)} = \left( \frac{\sum \text{Earned Weights in Domain}}{\sum \text{Maximum Possible Weights in Domain}} \right) \times 100$$

### 3.1 Threshold Matrix Rules
* 80% to 100%: Green (#4CAF50) -> STATUS_ON_TRACK
* 50% to 79%: Yellow (#FFC107) -> STATUS_MONITOR
* Below 50%: Red (#F44336) -> STATUS_DELAY_RISK
